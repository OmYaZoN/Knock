Notch Flasher

Turns this phone into a timed white/black light so the Mac's light sensor test can measure a real tap. Open this on the phone, not the Mac.

Pattern

Flashes about once a second. Skip this if flashing light affects you.

Hold a solid colour
How to run the test
  1. Set the phone to maximum brightness and turn off auto-brightness.
  2. On the Mac: ./alsprobe -t 40 -c run3.csv
  3. Here: tap Start, then press the top of the screen flat on the notch within 4 s.
  4. Hold it there. Tap the phone screen anywhere to stop.
  5. Send run3.csv and the times you picked.
